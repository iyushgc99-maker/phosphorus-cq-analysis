# Phosphorus C-Q Analysis

This project provides an R workflow for analyzing relationships between stream discharge (Q) and total phosphorus concentration (TP).

The workflow will be used to:

- import phosphorus and discharge data
- clean missing or invalid values
- fit log-log concentration-discharge relationships
- calculate slope, R², and p-values
- identify enrichment or dilution patterns
- create C-Q plots
- export summary results

## Why this project?

Concentration-discharge relationships can help show how phosphorus transport changes with streamflow and can provide information about possible hydrologic transport pathways.
